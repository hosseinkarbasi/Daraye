# دارایی من ۲.۳ — دانلود APK

فایل `Darayi-2.3-debug.apk` نسخهٔ آزمایشی اندروید ۸ به بالا است. برای دانلود، لینک Raw فایل را باز کنید. نسخه را روی برنامهٔ قبلی نصب کنید و برنامهٔ قبلی را حذف نکنید تا اطلاعات روی گوشی باقی بماند.

در این نسخه:
- کارت دارایی فقط درصد تغییر را نشان می‌دهد؛ متن دوره حذف شده است.
- نام دارایی در فرم افزودن و ویرایش قابل جست‌وجو است و نماد و نام شرکت پیشنهاد می‌شود.
- فیلد نماد منبع و ورودی واحد مقدار حذف شده‌اند؛ واحد از دارایی انتخاب‌شده تعیین می‌شود.
- فهرست اولیهٔ واقعی برای جست‌وجوی محلی همراه برنامه است؛ قیمت‌های جاری از سرویس‌ها دریافت می‌شوند.
- دریافت خودکار قیمت هنگام ورود و برگشت به برنامه و هشدار خطاهای دریافت برقرار است.

کلیدهای BRSAPI و نوسان را در تنظیمات خود برنامه وارد کنید. نوبیتکس برای دریافت قیمت عمومی کلید نمی‌خواهد. هیچ کلید API یا قیمت ساختگی در APK قرار ندارد.

ساخت APK، ۴۸ تست واحد و lint در ۲۰۲۶-۱۰-۱۰ موفق بودند. شناسهٔ برنامه `com.darayi.app`، نسخهٔ ۲.۳ با کد ۶ و امضای توسعه با نسخهٔ ۲.۲ یکسان است. رابط روی گوشی واقعی یا شبیه‌ساز در این محیط آزمایش نشده است. فایل SHA-256 کنار APK برای بررسی دانلود قرار دارد.
