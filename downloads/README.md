- دکمهٔ ذخیرهٔ ثابت پایین صفحه و فرم قابل اسکرول هنگام باز بودن صفحه‌کلید.
- مقدار دارایی با فونت کوچک‌تر و کم‌رنگ‌تر (۱۲) کنار نام نیمه‌پررنگ (۱۵).
